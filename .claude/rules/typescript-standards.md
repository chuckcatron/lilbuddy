# TypeScript Standards

## Applies To

All TypeScript projects. Does NOT apply to `verdant_web_thermostat_solutions` (PHP).

## Code Quality (CRITICAL)

- ALWAYS run IDE diagnostics after editing files
- Fix all linting and type errors before completing tasks
- This step must NEVER be skipped

## Rules

- Strict mode enabled
- No `any` type — use proper types, generics, or `unknown`
- Prefer interfaces over type aliases for object shapes
- Use explicit return types on exported functions
- Alphabetize imports
