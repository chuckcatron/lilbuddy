# Azure DevOps Workflow

## Work Items

- All planned work must reference an Azure DevOps work item (AB#number)
- Commits must include the AB# reference in the scope: `type(AB#number): subject`
- PR descriptions should reference the relevant work items

## During Development

- Update work item status as work progresses
- Add comments to work items when deviating from the original plan
- Link PRs to work items
