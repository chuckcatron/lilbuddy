# Testing Gates

## Requirements

- Write tests for all new features
- Run existing tests before completing tasks
- Focus on end-to-end tests over unit tests
- Use test-driven development for complex features

## Coverage

- Minimum 80% test coverage on all TypeScript projects
- Per-project thresholds may override this in their own CLAUDE.md
- Legacy PHP projects are exempt

## Before Review

1. All tests must pass
2. Coverage must meet the project threshold
3. No skipped tests without documented reason
4. Fix failing tests before proceeding to review

## Before Merge

- CI pipeline must pass
- No regressions in existing test suites
