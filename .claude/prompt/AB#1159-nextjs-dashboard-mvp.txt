## Constraints

### Pattern Conformance (MANDATORY — read before you write)

Before writing ANY new code, you MUST:

1. **Read `packages/shared/src/session-state.ts` and `packages/shared/src/token-usage.ts`** — understand SessionState, TokenUsage, totalTokens(). The dashboard will use these types.
2. **Read `apps/convex/convex/schema.ts`** — understand the flat field structure returned by Convex queries. The document shape differs from `SessionState` (flat tokens, string notificationState).
3. **Read `apps/convex/convex/sessions.ts`** — understand what `getActive` returns (all fields of the sessions document).
4. **Read `apps/bridge/vitest.config.ts`** — match test conventions (vitest, explicit imports, V8 coverage, 80% thresholds).
5. **Read `apps/bridge/package.json`** — match workspace dep pattern.
6. **Follow Next.js 15 App Router conventions** — `"use client"` directives, layout/page structure, metadata exports.
7. **Follow Convex React conventions** — `ConvexReactClient`, `ConvexProvider`, `useQuery` with typed `api` object.

### Data Shape Mapping

The Convex `sessions.getActive` query returns documents with these fields (NOT the `SessionState` interface):
- `sessionId`, `userId`, `model`, `cwd` — strings
- `currentTool`, `currentTarget`, `lastAssistantMessage`, `notificationMessage` — optional strings
- `notificationState` — string: `"none"` | `"permission_prompt"` | `"idle_prompt"`
- `inputTokens`, `outputTokens`, `cacheCreationInputTokens`, `cacheReadInputTokens` — numbers
- `permissionMode` — string
- `isActive` — boolean
- `startedAt`, `updatedAt` — numbers (timestamps)
- `_id`, `_creationTime` — Convex system fields

To use `totalTokens()` from `@lilbuddy/shared`, construct a `TokenUsage` object from the flat fields.

### Convex API Import Strategy

The `api` object for `useQuery(api.sessions.getActive)` lives in `apps/convex/convex/_generated/api.ts`. Options to make it importable from `apps/web`:
- **Recommended:** Re-export from `apps/convex/package.json` exports field, then import as workspace dep
- **Alternative:** Relative import `../../convex/convex/_generated/api` with TypeScript path alias
- **Alternative:** Run `npx convex codegen` in `apps/web` with a `convex.json` pointing to the shared functions dir

Choose the simplest approach that maintains type safety.
