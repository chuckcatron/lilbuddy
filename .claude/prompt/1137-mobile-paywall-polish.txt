## Constraints

- Lock icon pattern: `<Text style={{ fontSize: 12 }}>🔒</Text>` (emoji, consistent with StreakCalendar and team.tsx)
- All CTAs navigate via `router.push("/paywall")` — never deep link or external URL
- Indicators must be **subtle** — never hard-block access to existing free features
- Premium users must see zero upsell UI (no lock icons, no counts, no CTAs)
- Do not modify the existing dismissible banner in habits.tsx (lines 122-159)
- No `any` types — strict TypeScript
- 80% minimum test coverage on modified files

## Expected Output

1. **habits.tsx** shows `X/3 habits used 🔒` in header subtitle for free users with 1+ habits
2. **dashboard.tsx** shows upgrade CTA card for free users between MotivationalQuote and Today's Habits
3. Both indicators navigate to `/paywall` on tap
4. Premium users see original "Build your habit stacks" subtitle and no dashboard CTA
5. Existing dismissible banner continues to work unchanged
6. All tests pass, coverage >= 80%

## Edge Cases

| Scenario | Expected Behavior |
|----------|-------------------|
| `habitCounts` is `undefined` (loading) | Show original subtitle "Build your habit stacks" |
| Free user with 0/3 habits | Show original subtitle (no count indicator yet — nothing to count) |
| Free user with 3/3 habits (at limit) | Show "3/3 habits used 🔒" in persistent indicator AND dismissible banner |
| Premium user | No persistent count, no dashboard CTA, no lock icons |
| `useSubscription().loading` is true | Hide premium-gated UI until loaded (avoid flash) |
